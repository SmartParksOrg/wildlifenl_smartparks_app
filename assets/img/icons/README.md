# Marker icons

The same icons Smart Parks Protect draws in its map markers. They are EarthRanger's icons from the open source EarthRanger server (https://github.com/PADAS/er-server, Apache License 2.0), as normalised in the Protect repository: a square `viewBox`, `fill="currentColor"` and nothing baked in.

`speciesIcon` in `assets/js/lib.js` picks the file from the Latin name of a species.

`person.svg` and `alarm.svg` are drawn for this app and fall under its MIT licence.
